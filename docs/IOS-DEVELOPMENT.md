# iOS Development

Status: scaffold planning only.

iOS cannot be built or verified from this Windows machine. The current reusable assets are the domain model, service contracts, and database schema concepts. A real iOS client should share contracts and safe workflow behavior, not WPF UI code.

Required:

- macOS with Xcode.
- Apple Developer account.
- Bundle identifier.
- Signing team.
- Secure storage implementation for credentials.
- Diagnostic export/share sheet.
