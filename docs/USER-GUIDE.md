# User Guide

1. Open the app.
2. Run **Dry-run migration** to inspect existing PowerShell JSON data.
3. Use the migrator with `--apply --allow-live` when ready.
4. Use **Scan roots** to index configured source roots.
5. Select a row to preview the image.
6. Use filters for Not Listed, unreviewed OCR, missing files, and text search.
7. Use **OCR selected** to run local Tesseract OCR.
8. Use **Export selected** to copy grouped images into the eBay temp export folder.

The app keeps database metadata independent of physical folder location.
