# eBay Sandbox Testing

Sandbox connection requires Sandbox app keys and a Sandbox user account.

Workflow:

1. Enter Sandbox credentials and RuName.
2. Start OAuth authorization.
3. Complete consent in the external browser.
4. Store tokens through secure local storage.
5. Refresh capability status.
6. Retrieve account policies and validate draft listing data.

CI does not require live or Sandbox credentials.
