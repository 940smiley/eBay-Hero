# Privacy

eBay Assistance is local-first. Inventory data, image paths, OCR text, listing drafts, and diagnostics should remain on the user's machine unless the user explicitly exports or shares them.

Do not include in diagnostics by default:

- API keys or OAuth tokens.
- Full database files.
- Raw card or inventory images.
- Buyer data.
- Payment data.
- Full inventory exports.

Cloud AI, pricing-data providers, eBay APIs, and future sync features may introduce external data processing. Those features require explicit configuration, privacy review, and user-facing disclosure before public release.
