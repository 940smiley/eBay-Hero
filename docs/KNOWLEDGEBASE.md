# KnowledgeBase

`D:\KnowledgeBase` is read-only by default.

Use `scripts\discover-knowledgebase.ps1 -DryRun` to find relevant metadata for eBay, OAuth, OpenAI, OCR, inventory schemas, and listing templates. Use `scripts\import-secrets.ps1` only with a reviewed source JSON file.

Secrets are redacted from output and reports.
