# Roadmap

This roadmap assumes the product helps eBay sellers improve listing, pricing, inventory, research, or operations workflows.

## Phase 0: Repository Recovery and Release Baseline

- Connect or clone the actual source repository.
- Run the current test/build/lint workflow and document any failures.
- Identify the product shape and distribution target.
- Add CI for install, lint, test, and build.
- Add release documentation and versioning.
- Confirm eBay API usage and compliance boundaries.

## Phase 1: MVP Public Release

- Support one primary workflow end to end, such as listing optimization, listing draft generation, price research, or inventory review.
- Add clear onboarding for connecting an eBay account or importing listing data.
- Add safe defaults, validation, and recoverable errors.
- Add user-facing documentation for installation, setup, and troubleshooting.
- Publish a signed or store-approved release candidate.
- Run a small private beta before public download.

## Phase 2: Seller Productivity

- Add batch workflows for multiple listings.
- Add saved templates for common listing patterns.
- Add pricing and fee visibility before listing changes are applied.
- Add history, undo, or export support for changes made by the assistant.
- Add notification or review queues for listings that need seller attention.

## Phase 3: Paid Product

- Add account management, subscription state, and billing gates.
- Add usage limits by plan.
- Add analytics for activation, retention, conversion, churn, and feature usage.
- Add support workflows for refunds, account issues, and billing questions.
- Add team or multi-store support if seller demand supports it.

## Phase 4: Scale and Differentiation

- Add market research and competitor tracking.
- Add listing quality scoring and recommendations.
- Add automation rules with approval controls.
- Add integrations for spreadsheets, inventory systems, shipping tools, or accounting tools.
- Add multi-marketplace support only after the eBay workflow is stable and profitable.
