# Listings

Listings are marketplace-neutral drafts with an eBay adapter path.

Supported fields include listing kind, status, title, description, category, condition, price, auction/BIN, best offer, quantity, policies, handling time, item specifics, scheduled date, SKU, external listing ID, and URL.

Publishing is disabled by default. Listing drafts can be created from selected inventory rows and exported through the safe local eBay export workflow.
